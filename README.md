# 🎮 Tic-Tac-Toe

Remember this game??
Probably the last pages of our school notebooks were filled with **X's and O's**!

I recreated that simple childhood game using Java — this time, instead of a pen and paper, you can play it against a small AI opponent.

### 🛠️ Built With

* Java
* OOP Concepts
* 2D Arrays
* Random class
* Scanner

### 🎯 Features

* Human vs AI
* Random AI moves
* Win and draw detection
* Simple console-based gameplay

A small project, but a fun way to practice Java while bringing back a little nostalgia! ❤️

**Have fun playing!**
